\begin{abstract}
% This work builds on a B.Sc.\ thesis in Data Science at the University of Buenos Aires (Faculty of Exact and Natural Sciences),
% supervised by Eric Brandwein, and continues in the current manuscript.

We study a systematic family of graph parameters defined via \emph{forbidden colored patterns} on ordered triples of vertices.
Given a small set of patterns on three vertices, the parameter is the minimum number of parts in a vertex partition, together with a vertex order, that avoids all patterns for every ordered triple of vertices.
This framework is inspired by the thinness graph parameter and its variants and provides a uniform way to
generalize graph classes and measure distance to them.
We analyze several families motivated by star-like, bipartite-like, and forest-like constraints, identify collapses to classical
invariants in multiple cases, and outline complexity and algorithmic directions suggested by the resulting landscape.
\end{abstract}

\section{Motivation}

A \emph{pattern} is a small template that specifies a combination of edges and non-edges in a set of ordered vertices. Many graph classes can be characterized by the existence of a total vertex order that avoids a specific pattern on three vertices, for every ordered triple of vertices. For instance, interval graphs \cite{LekkerkerkerBoland1962,FulkersonGross1965} are exactly the graphs that admit an order avoiding the pattern where \(u\) and \(w\) are adjacent, \(v\) and \(w\) are non-adjacent, and no other edges are required or forbidden. A systematic study of graph classes defined by forbidden patterns on three vertices was carried out by \textcite{FeuilloleyHabib2018}.

The thinness graph parameter can be seen as an extension of this concept. Introduced by \textcite{Mannino2007}, thinness is defined by the minimum number of parts in a vertex partition, together with a vertex order, that avoids a specific \emph{forbidden colored pattern} on three vertices. A colored pattern on three vertices is a pattern that additionally specifies which vertices must lie in the same part of the partition. A precise definition is given in \cref{sec:framework-patterns}.

Thinness generalizes interval graphs in the sense that interval graphs are exactly the graphs of thinness~$1$ \cite{Mannino2007}.
A common motivation in the literature is that bounded thinness can be used to extend algorithmic techniques beyond interval graphs:
many problems that are hard in general admit polynomial-time algorithms on graphs of bounded thinness, provided that an explicit certificate (order + partition) is available \cite{BonomoDeEstrada2019}.

One could define other graph parameters by forbidding different colored patterns on three vertices, or by forbidding multiple patterns simultaneously. This is for example the case for proper thinness, which can be defined by forbidding the thinness pattern and its mirror image at the same time. Proper thinness generalizes proper interval graphs, which are exactly the graphs of proper thinness~$1$ \cite{BonomoDeEstrada2019}.

This motivates a broader question: what happens if we take \emph{other} small collections of forbidden colored patterns
and define a parameter as the minimum number of parts in an order+partition certificate needed to avoid them?
If these parameters preserve useful properties of the underlying class they generalize,
then problems solvable efficiently on that class may remain solvable (or become parametrically tractable)
when the parameter is bounded.

This perspective parallels a familiar theme in width parameters. Treewidth and pathwidth generalize trees and paths via
tree/path decompositions, and many algorithmic techniques become efficient on graphs of bounded treewidth once a suitable
decomposition is available; see, for example, \textcite{Bodlaender1993}.
Algorithmic meta-theorems, such as Courcelle's theorem, further show that many logic-definable graph properties become tractable
on graphs of bounded treewidth \cite{Courcelle1990}.




\section{Objectives}
The main goal of this research program is to systematically analyze the family of graph parameters obtained by forbidding combinations of colored patterns on three vertices. This includes:
\begin{itemize}
  \item Determining the complexity of computing each parameter.
  \item Positioning each parameter in the landscape of graph parameters by identifying collapses to classical invariants (e.g., vertex arboricity, chromatic number) and establishing domination relations.
  \item Finding algorithmic applications for problems that are tractable when the parameter is bounded, and understanding the role of the certificate structure in such algorithms.
\end{itemize}

We begin by analyzing colored patterns where the non-edge set is empty. Ignoring the coloring constraints, these still correspond to the forbidden patterns of interesting graph classes, such as the class of all stars ($K_{1,n} + cK_1$), bipartite graphs ($K_{m,n}$), and forests, among others.









\section{Framework: forbidden colored patterns}\label{sec:framework-patterns}

\begin{definition}[Colored pattern on three vertices]
A \emph{colored pattern} is a triple \(P=(A,N,C)\) where
\[
A,N \subseteq \binom{\{r,s,t\}}{2},
\qquad
C \in \binom{\{r,s,t\}}{2}.
\]
Here \(r,s,t\) denote the positions of an ordered triple \(r\prec s\prec t\), and
\[
\binom{\{r,s,t\}}{2}=\{\{r,s\},\{r,t\},\{s,t\}\}.
\]
The set \(A\) specifies the pairs that must be edges, \(N\) specifies the pairs that must be non-edges,
and \(C\) specifies the pair of positions that must lie in the same part of the partition.
\end{definition}

\begin{definition}[Solution and value]
Let \(G\) be a graph. A \emph{solution} for $G$ is a pair \(S=(\prec,\mathcal Q)\), where \(\prec\) is a total order on \(V(G)\)
and \(\mathcal Q=\{V_1,\dots,V_k\}\) is a partition of \(V(G)\) into \(k\) parts.
The \emph{value} of \(S\) is \(|\mathcal Q|=k\).
\end{definition}

\begin{definition}[Avoiding a pattern]
Fix a graph \(G\) and a solution \(S=(\prec,\mathcal Q)\) for $G$.
Given three distinct vertices \(v_1\prec v_2\prec v_3\) in $V(G)$,
we say \((v_1,v_2,v_3)\) \emph{avoids} the colored pattern \(P=(A,N,C)\) if at least one of the following holds:
\begin{enumerate}
\item For some $\{i, j\} \in A$, we have that $\{v_i,v_j\} \notin E(G)$.
\item For some $\{i, j\} \in N$, we have that $\{v_i,v_j\} \in E(G)$.
\item If $C = \{i,j\}$, then \(v_i\) and \(v_j\) lie in different parts of \(\mathcal Q\).
\end{enumerate}
The solution \(S\) \emph{avoids} \(P\) if every triple \(x\prec y\prec z\) avoids \(P\).
For a family of colored patterns \(\mathcal P\), the solution avoids \(\mathcal P\) if it avoids each \(P\in\mathcal P\).
\end{definition}

\begin{definition}[Parameter induced by forbidden patterns]
For a finite family of patterns \(\mathcal P\), define \(\minClases_{\mathcal P}(G)\) as the minimum value of a solution for $G$ that avoids \(\mathcal P\).
\end{definition}

We sometimes refer to a solution that avoids a family of patterns as a \emph{certificate} for the avoidance of those patterns.

We started with three families of colored patterns, each obtained from a fixed uncolored pattern
on three ordered vertices \(r\prec s\prec t\), and then varying which pair of positions is required
to lie in the same part.

\begin{itemize}
\item \textbf{Star graphs.}
The underlying uncolored pattern is given by
\[
A=\bigl\{\{r,s\}\bigr\},
\qquad
N=\varnothing.
\]

Avoiding this pattern with one part characterizes star graphs, possibly with isolated vertices.
We study the three colored versions obtained by choosing \(C=\{r,s\}\), \(C=\{s,t\}\), or \(C=\{r,t\}\),
and also combinations of these colored patterns. Several of the resulting parameters collapse
to vertex cover or chromatic number.

\item \textbf{Bipartite graphs.}
The underlying uncolored pattern is given by
\[
A=\bigl\{\{r,s\},\{s,t\}\bigr\},
\qquad
N=\varnothing.
\]

Avoiding this pattern with one part is equivalent to being bipartite.
Again, we study the three colored versions, obtained by choosing the colored pair \(C\), and their combinations.
Some of the resulting parameters admit clean exact formulas in terms of \(\chi(G)\).

\item \textbf{Forests.}
The underlying uncolored pattern is given by
\[
A=\bigl\{\{r,t\},\{s,t\}\bigr\},
\qquad
N=\varnothing.
\]

Avoiding this pattern with one part is equivalent to being a forest.
We study the corresponding colored versions and their combinations. One of these parameters matches
vertex arboricity, while several others do not seem to collapse to standard parameters and appear
structurally richer. We also studied variants in which either the order or the partition is given
as part of the input.
\end{itemize}
\medskip



For each of the three families above, we denote by \(P_{rs}\), \(P_{st}\), and \(P_{rt}\)
the colored patterns obtained from the same underlying uncolored pattern by choosing,
respectively,
\[
C=\{r,s\},\qquad C=\{s,t\},\qquad C=\{r,t\}.
\]

When we write, for instance,
\[
\mathcal P_{rs\text{-}st}:=\{P_{rs},P_{st}\},
\qquad
\mathcal P_{rs\text{-}st\text{-}rt}:=\{P_{rs},P_{st},P_{rt}\},
\]
the combination is taken \emph{within the same family}. Thus, in the star family,
\(\mathcal P_{rs\text{-}st}\) means that we forbid both star-colored patterns \(P_{rs}\) and \(P_{st}\);
in the bipartite family, it means forbidding both bipartite-colored patterns; and similarly for forests.

\section{Future directions}

\begin{itemize}
\item \textbf{Complete the forest family.}
  A first direction is to complete the analysis of the parameters obtained from the colored patterns associated with forests.
  In the current work we have analyzed several one-pattern and two-pattern families, but a complete classification is still open.
  This includes:
  \begin{itemize}
  \item determining whether the remaining parameters coincide with known graph parameters or define genuinely new ones;
  \item completing the complexity landscape, distinguishing polynomial-time cases from NP-hard cases;
  \item studying restricted input variants, for example the problem of deciding the parameter when the vertex order is given
  as part of the input, or when the partition is given as part of the input.
  \end{itemize}

\item \textbf{Compare with other graph parameters.}
  A useful structural goal is to relate these parameters to established ones, such as treewidth, pathwidth,
  vertex arboricity, vertex cover, and coloring-based measures.
  Inequalities between parameters can transfer algorithmic information. For instance, if two parameters \(p\) and \(q\)
  satisfy
  \[
  p(G)\le f(q(G))
  \]
  for some computable function \(f\), then every class of graphs with bounded \(q\) also has bounded \(p\).
  Consequently, algorithms that are efficient for bounded \(p\) may also be applicable when \(q\) is bounded,
  provided that the required certificates can be obtained or are given as part of the input.

  Conversely, proving that a parameter is not controlled by another one can help explain why certain algorithmic
  techniques do not transfer. Establishing such comparisons would clarify where the parameters defined by forbidden
  colored patterns sit among standard graph measures.

\item \textbf{Combine patterns associated with different graph classes.}
  Another direction is to study families of forbidden colored patterns obtained by combining patterns associated with
  different graph classes. If one pattern defines a class \(\mathcal C_1\) and another defines a class \(\mathcal C_2\),
  then forbidding both patterns with one part corresponds to the intersection
  \[
  \mathcal C_1\cap \mathcal C_2.
  \]
  Thus, the resulting parameter can be viewed as a way of measuring distance to an intersection of graph classes.
  Such hybrid families may be more structured than the individual ones, and it is natural to ask whether some of them
  are easier to compute or admit stronger algorithmic applications.

\item \textbf{Algorithmic applications under bounded parameters.}
  Beyond identifying a parameter with a classical invariant, an important goal is to find concrete graph problems
  that become tractable when the parameter is bounded. There are two natural versions of this question:
  \begin{itemize}
  \item the algorithm receives only the graph and the parameter is known to be bounded;
  \item the algorithm receives, in addition, a certificate \(S=(\prec,\mathcal Q)\) avoiding the relevant family of patterns.
  \end{itemize}

  The second version may be easier and can still be useful: it may show that the structure of the certificate
  (the order and the partition), not only the numerical value of the parameter, is algorithmically meaningful.
  In particular, for parameters that do not seem to collapse to standard measures, it is worth searching for problems
  that are tractable under these parameters but not known to be tractable under more classical ones. This would position
  forbidden-pattern parameters as an additional tool in the graph algorithm toolbox.

  In the language of parameterized complexity, the goal is to obtain algorithms of the following types:
  \begin{itemize}
  \item \textbf{FPT:} running time \(O(f(k)\cdot n^c)\), where \(k\) is the parameter, \(c\) is a constant, and \(f\)
  is a computable function;
  \item \textbf{XP:} running time \(O(f(k)\cdot n^{g(k)})\), for computable functions \(f\) and \(g\).
  \end{itemize}
\end{itemize}
